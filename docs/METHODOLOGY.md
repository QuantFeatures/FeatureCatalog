# Methodology

QuantFeatures transforms licensed exchange event feeds into interval-based research features. The engine replays sequential event data, normalizes venue and instrument identifiers, applies source-quality checks, and emits versioned Parquet records.

Public documentation describes source classes, interval semantics, units, quality treatment, and feature interpretation. It does not disclose proprietary formulas, state-management algorithms, initialization procedures, or numerical implementation details.

Derived-data publication is subject to the applicable source and exchange redistribution rights. No statement in this documentation grants rights to underlying event data.
